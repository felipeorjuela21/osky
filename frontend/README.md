# Frontend

Interfaz de Osky (React + TypeScript + Vite). `npm install && npm run dev` → http://localhost:5174 (proxy /api → :8000).

Logo: `public/oski.png` (si no existe se usa `public/oski.svg`).

Responsabilidades:
- interfaz conversacional
- captura de micrófono
- reproducción de audio
- estado del agente
- posteriormente avatar 2D/3D

No debe contener reglas de negocio ni acceso directo a PostgreSQL.
