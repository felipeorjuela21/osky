# Carpeta de conocimiento de Osky

Deja aquí documentos de CeluWeb para que Osky los use al responder:
fichas de producto, preguntas frecuentes, brochures, políticas, procesos, etc.

- Formatos: **PDF**, **Word (.docx)**, **texto (.txt)** y **Markdown (.md)**.
- El nombre del archivo se usa como título de la fuente: `Ficha TMS.pdf` → "Ficha TMS".
- Osky responde **solo** con lo que dicen estos documentos, el sitio web y `config/company_facts.json`.
- Los cambios se aplican solos (no hay que reiniciar). En el servidor publicado, se suben a GitHub y Render
  vuelve a desplegar automáticamente.
- No pongas aquí información confidencial: lo que esté en esta carpeta Osky se lo puede decir a cualquier visitante.

Este archivo (LEEME) no se indexa.
